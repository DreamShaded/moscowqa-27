# moscowqa-27

Доклад для митапа MoscowQA 27. Слайды на [Slidev](https://sli.dev), тема — вендорная
копия `slidev-theme-vzhyx` внутри репозитория (`./slidev-theme-vzhyx`).

## Команды

```bash
pnpm install
pnpm dev       # локальный сервер с автообновлением
pnpm build     # прод-сборка в dist/
pnpm export    # экспорт в PDF/PNG
```

## Деплой

Пуш в `main` собирает колоду и публикует её на GitHub Pages
(`.github/workflows/deploy.yml`) — https://dreamshaded.github.io/moscowqa-27/
